Publish a game

HTML/CSS/JS, C, C++, or Wasm builds only

Log in to publish a game.

One single .html file with its CSS/JS inline or loaded from a CDN — this gets hosted on nexHub itself and becomes playable in-browser once approved. Multi-file bundles/zips aren't supported yet.

Submitting queues your game for review (typically 10–30 minutes). This demo stores the request in Firestore as "pending_review" — actually building/scanning C, C++, and Wasm submissions requires a backend build service that isn't part of this static page. Wire your own reviewer or Cloud Function to read this collection and flip the status.

Emulators

Play your own legally-owned ROMs — nothing is hosted here

Runs real classic-console emulator cores (NES, SNES, Game Boy Advance/Color, N64, PlayStation) fully in your browser via the open-source EmulatorJS project. You supply your own ROM file that you legally own — nexHub doesn't include, host, or link to any copyrighted game files.

Android APK emulation (BlueStacks-style) isn't something a browser tab can do — that needs a real virtualized Android device, run locally or streamed from a server. That's a separate infrastructure project, not a feature this page can add.
