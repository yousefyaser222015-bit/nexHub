# nexHub
A modern web-based gaming platform inspired by Steam and built for discovery and retro gaming
منصه تشبه steam مصريه بالكامل تشبه steam في واجهه رسوميه توجد فيه العاب كثيره تظهر يمكنك تحميل العاب قديمه وتشغيلها في منصه كما توجد فيه اماكن ل مبرمجين ل نشر العاب ومكان يتم عرض فيه العاب قديمه كما يوجد فيه درع تحكم تتحرك به توجد عده اصدارات قديمه وهذا احدث اصدار حالي
يمكنك ان تستخدمها وتشبه steam لكنها تختلف في نظام دفع لانها لا يتوفر بها اصدارات دفع يمكنك ان تحمل هذا ملف ويتم تشغيله في متصفح وسوف تري واجهه رسوميه ونظام بالكامل وتجربته
